## Software Development Life Cycle

- Requirement Analysis
- Design
- Coding
- Testing
- Deployment
- Maintanace

## Software Testing Life Cycle

- It’s a part of the SDLC and talks about testing process

### 1) Requirement Analysis

- Understand customer’s requirement

### 2) Test Planning

- We need a proper plan before any test
- Identify
    - What to test: what things of the application have to test
    - How to test: tools, type of testing
    - When to test: because we have different cycles and we need to specify the time which day to which day we have to conduct the testing and how many hours
- Documents
    - Project Plan: it’s a high level document close to the high level of manager
    - Functional Requirements: we need to identify the scenarios and it has a relationship with what to test

### 3) Test Design/Development

- We write the test cases and test scenarios
- Functional requirements are the main documents of this phase. Contains:
    - how many features will be tested and what features will be tested
    - How the application will behaved
- Design Docs is because we need to know how is the UI
- The Uses Cases describes the requirements and help us to understand the requirements more clearly
- Test Scenarios means what to test, identify the parts of the application that can be tested. It’s a high level requirement
- Test Cases are the actions which we have to perform to test the functionality of our application. They are multiple
- Traceability Matrix: documents that maps requirements with its test cases
- Test Cases Sign-Off (aprobación) are like a proof (prueba)

### 4) Test Execution

- Build from Development Team: it’s the software o peace of the software that contains multiple features
- Main activities: Executing Test Cases and identifying defects
- Create a test report while execute test cases. How many test cases are there, how many test cases pass, how many test cases fail

### 5) Defect/Bug Reporting And Tracking

- Main thing: preparer the defect report

### 6) Test Closure/Sign-Off

- We ending our testing
- Before stop our testing, we conduct a meeting with the analysis of test reports, defect reports
